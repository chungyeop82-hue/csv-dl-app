# Windows 배치 파일(.bat) 한글 인코딩 관리 (STEP 9)

`dist/` 안의 `*.bat` 파일(시작.bat, 시작_GPU.bat, 종료.bat, 초기화.bat, 진단.bat,
offline 폴더의 두 스크립트)은 한글 안내 문구를 담고 있습니다. cmd.exe는 기본적으로
시스템 로캘의 OEM 코드 페이지(한국어 Windows에서는 CP949, 코드 페이지 949)로 배치
파일을 읽으므로, **UTF-8로 저장하면 실행 시 한글이 깨집니다.**

## 규칙

1. 이 저장소의 `*.bat` 파일은 항상 **CP949(ANSI/OEM 한국어) 인코딩, BOM 없음, CRLF 줄바꿈**으로 저장합니다.
   - UTF-8, UTF-8 BOM으로 저장하면 실행 시 한글이 깨지거나(UTF-8) 첫 줄에 이상한 문자가 보이며
     명령이 인식되지 않을 수 있습니다(BOM).
   - `.gitattributes`는 `*.bat text eol=crlf`로 **줄바꿈만** 강제합니다. 파일의 바이트 인코딩 자체는
     Git이 대신 바꿔주지 않으므로, 편집한 사람이 저장할 때 직접 CP949로 저장해야 합니다.
2. 모든 `.bat` 파일은 첫 줄 근처에서 `chcp 949 >nul` 을 실행해, 시스템 기본 코드 페이지가
   다르게 설정된 PC에서도 같은 코드 페이지로 화면에 출력합니다.
3. 배치 파일 문구에는 `→`, `★` 같은 특수 기호나 이모지를 쓰지 않습니다. CP949로 표현되지 않는
   글자가 섞이면 저장 자체가 실패하거나 물음표로 깨집니다. 화살표가 필요하면 `->` 대신 문장을
   풀어 씁니다(예: "확인 방법: ..." 처럼).

## 편집 도구별 저장 방법

### VS Code

1. 파일을 열고 우측 하단 상태 바의 인코딩 표시를 클릭합니다(기본은 대개 UTF-8로 보입니다).
2. "인코딩하여 저장"을 선택하고 목록에서 "Korean (CP949)"를 고릅니다.
3. VS Code가 CP949 표시가 없다면 설정(`files.encoding`)에서 `cp949`를 추가하거나,
   내장 인코딩 목록에 없을 때는 아래 PowerShell 방법을 사용합니다.

### 메모장(Notepad)

1. 파일 - 다른 이름으로 저장을 선택합니다.
2. 인코딩 드롭다운에서 "ANSI"를 선택합니다(시스템 로캘이 한국어이면 ANSI = CP949).
3. 파일명과 확장자(.bat)를 원래 이름 그대로 유지합니다.

### PowerShell로 일괄 변환 (UTF-8로 잘못 저장된 파일을 되돌릴 때)

```powershell
$cp949 = [System.Text.Encoding]::GetEncoding(949)
$utf8  = [System.Text.Encoding]::UTF8
$path  = ".\시작.bat"
$text  = [System.IO.File]::ReadAllText($path, $utf8)
[System.IO.File]::WriteAllText($path, $text, $cp949)
```

- `GetEncoding(949)`는 시스템 로캘과 무관하게 항상 CP949를 사용하므로, 영문 Windows에서
  작업할 때도 정확한 결과를 보장합니다.
- 여러 파일을 한 번에 변환하려면 `Get-ChildItem *.bat`으로 반복문을 돌리면 됩니다.

## 확인 방법

1. 변환한 `.bat` 파일을 실제 Windows PC에서 더블클릭해 실행합니다.
2. cmd 창에 한글이 `¤ª`, `┐├` 같은 깨진 문자 없이 정상적으로 보이는지 확인합니다.
3. 첫 줄에 보이지 않는 문자(BOM)로 인해 `'▒■@echo'은(는) 내부 또는 외부 명령...`처럼
   나오면 BOM이 남아 있는 것이므로 BOM 없이 다시 저장합니다.

## 이번 작업 확인 상태

- 이 저장소의 CP949 변환은 클라우드(Linux) 작업 환경에서 Python으로 UTF-8 -> CP949, LF -> CRLF
  변환을 거쳐 커밋했습니다. 변환 후 각 글자가 CP949로 정상 인코딩되는지(인코딩 오류 없음)는
  확인했지만, **실제 Windows cmd.exe 창에서 더블클릭 실행해 한글이 올바르게 보이는지는
  Windows PC에서 직접 확인이 필요합니다.**
